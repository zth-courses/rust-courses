# Rust 语言学习教程

这个项目包含了一系列Rust语言学习教程，从基础概念到高级特性，帮助你系统地学习Rust编程语言。

## 教程内容

本教程包含以下主题：

1. **变量和数据类型** - 介绍Rust中的变量声明、基本数据类型和复合类型
2. **函数和流程控制** - 学习函数定义和各种流程控制结构（if、loop、while、for、match）
3. **所有权系统** - 深入理解Rust最独特的特性：所有权、借用和生命周期
4. **结构体、枚举和模式匹配** - 学习如何使用结构体和枚举组织数据，以及强大的模式匹配
5. **集合类型** - 掌握Vector、String和HashMap等常见集合类型
6. **包和模块系统** - 了解如何组织和管理代码
7. **错误处理、泛型、Trait和生命周期** - 学习Rust的高级特性

## 如何使用

每个教程文件都是一个独立的可执行程序，包含了详细的注释和示例代码。

### 运行示例

你可以使用以下命令运行任何一个示例：

```bash
# 运行变量和数据类型示例
cargo run --bin 01_variables_and_data_types

# 运行函数和流程控制示例
cargo run --bin 02_functions_and_control_flow

# 运行所有权示例
cargo run --bin 03_ownership
```

### 学习建议

1. 按照编号顺序学习，从基础到高级
2. 尝试修改示例代码，观察结果变化
3. 阅读代码中的注释，理解每个概念
4. 尝试编写自己的小程序，应用所学知识
