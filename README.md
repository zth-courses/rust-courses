# Rust 基础代码笔记合集

这是一个 Rust 编程语言的基础代码示例合集，包含了各种 Rust 核心概念和特性的示例代码。

## 目录结构

- `vector_demo/` - Vector 集合类型示例
- `tuple-demo/` - 元组类型示例
- `string_demo/` - 字符串处理示例
- `struct_demo/` - 结构体示例
- `rust_packages/` - Rust 包管理示例
- `rust_day1/` - Rust 第一天学习笔记
- `panic_demo/` - 错误处理示例
- `owner_demo/` - 所有权系统示例
- `option_demo/` - Option 类型示例
- `match_demo/` - 模式匹配示例
- `lifetime1_demo/` - 生命周期示例
- `if_demo/` - 条件语句示例
- `hashmap_demo/` - HashMap 示例
- `guessing_game/` - 猜数字游戏示例
- `fun_demo/` - 函数示例
- `for_demo/` - 循环示例
- `enum_demo/` - 枚举类型示例

## 运行说明

每个示例都是一个独立的 Rust 项目，你可以通过以下步骤运行任意示例：

1. 进入目标目录：
```bash
cd <示例目录>
```

2. 运行示例：
```bash
cargo run
```

## 环境要求

- Rust 1.70.0 或更高版本
- Cargo（Rust 包管理器）
